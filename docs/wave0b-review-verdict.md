## 4. CAN WAVE 1 START?

**No.** Three independent blockers, in the order they must be fixed:

1. **N3 — the tool produces wrong labels.** The soundness guarantee printed inside every row is false; 5/5 absent amount terms are false absences, 3/6 absence-driven `missing_citation` exclusions on uncited claims rule out the correct label, and the excerpt that would expose it is suppressed on exactly those rows. A reviewer obeying `bc-b30-03-add04 / claim-ce3be1a81f` lands on `genuine_answer_error`; the truth is `missing_citation`.
2. **N4 — no blinded instrument exists**, and the plan states the anchoring contamination cannot be repaired downstream. Labelling against this export burns the 71-row gold set permanently.
3. **N5 — no gold negatives.** Without the mandated ≥40-row seeded stratified sample of the 94 supported claims, Gate 2's `recall == 1.000` is vacuous, so nothing in Wave 2 would be measurable even after 1 and 2 land.

Land in the same pass, since each independently bit R3's five-row exercise: **N14** (12/71 rows show zero evidence text), **N15** (`verifier_false_positive` unreachable for 34% of rows), **N16** (every documented command exits 2; release identity unsettled).

# Supporting Documents for Funding Proposal

## I. NDA No-Objection Letter (Market Study)

### Description:
A letter from a third party confirming that there are no objections to the project proposal.

## II. Integrated Financial Model that provides sensitivity analysis of critical elements (xls format, if applicable)

### Description:
A financial model that includes sensitivity analysis of critical elements in the project. The model should be presented in an xls format and include all necessary details for a comprehensive understanding of the project's financial implications.

## III. Project Programme Confirmation/Terms Sheet (including cost/budget breakdown, disbursement schedule, etc.)

### Description:
A confirmation or terms sheet that outlines the project programme, including the cost and budget breakdown, as well as the disbursement schedule for each phase of the project. The document should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

## IV. Environmental and Social Impact Assessment (ESIA) or Environmental and Social Management Plan (ESM) (if applicable)

### Description:
An Environmental and Social Impact Assessment (ESIA) or an Environmental and Social Management Plan (ESM) that outlines the potential environmental and social impacts of the project. The document should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

## V. Allocation Report or Due Diligence Report with recommendations (if applicable)

### Description:
An allocation report or due diligence report that outlines the allocation of resources for the project, including any recommendations for future funding opportunities. The document should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

## VI. Evaluation Report of the baseline project (if applicable)

### Description:
An evaluation report of the baseline project that outlines the results of the evaluation, including any recommendations for future funding opportunities. The document should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

## VII. Map indicating the location of the project/programme

### Description:
A map that indicates the location of the project or programme, including any relevant geographical information. The map should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

## VIII. Timetable for project/programme implementation

### Description:
A timetable for the implementation of the project or programme, including key milestones and deadlines. The timetable should be presented in a clear and concise manner to ensure easy understanding by all stakeholders.

**Please note that a funding proposal will be considered complete only upon receipt of all the applicable supporting documents.**
